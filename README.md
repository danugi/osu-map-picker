# osu! Map Picker

Локальное приложение для поиска и подбора карт osu!standard. Использует официальный osu! API v2, SQLite-каталог, фильтры и пресеты, анализ `.osu`-файлов и оценки пользователя.

Внутренний score от 0 до 100 нужен для сортировки результатов внутри выдачи. Это не вероятность качества карты и не PP. Калькулятора PP в проекте нет.

## Возможности

- Поиск карт через osu! API с кешированием и диагностикой запросов.
- Фильтры по режиму, статусу, звёздности, длительности и другим параметрам.
- Пресеты навыков и ранжирование по выбранным критериям.
- Локальная библиотека с фильтрами, сортировкой, избранным и историей.
- Случайная подборка из локального каталога без дополнительных API-запросов.
- Анализ доступных `.osu`-файлов и предварительный просмотр игрового поля без аудио.
- Локальные оценки, настройки, экспорт и резервное копирование.
- Фоновая очередь для постепенного анализа карт.

## Быстрый запуск в Windows

Требуется Python 3.12 или новее. Это запуск исходного проекта, а не автономный `.exe`.

1. Скачайте архив репозитория с GitHub и распакуйте его.
2. Установите Python с официального сайта: <https://www.python.org/downloads/windows/>. При установке включите добавление Python в `PATH`.
3. Запустите `run.bat` двойным щелчком.

При первом запуске скрипт создаст `.venv` и установит runtime-зависимости. После запуска приложение откроется в браузере и будет доступно только на этом компьютере через `127.0.0.1`. Для первоначальной установки зависимостей требуется интернет.

Чтобы остановить приложение, нажмите `Ctrl+C` в консольном окне.

## Настройка osu! API

Для получения новых карт нужны личные OAuth credentials.

1. Создайте OAuth-приложение: <https://osu.ppy.sh/home/account/edit#new-oauth-application>.
2. Для Client Credentials callback URL не требуется.
3. При запуске через `run.bat` введите Client ID и Client Secret в окне настройки либо откройте раздел `Настройки → API`.

В Windows credentials сохраняются в Windows Credential Manager. Если защищённое хранилище недоступно, приложение не сохраняет секрет в обычный файл и продолжает работать с локальным каталогом.

Для разработки можно использовать `.env` в корне репозитория. Создайте его на основе `.env.example`:

```dotenv
OSU_CLIENT_ID=your_client_id
OSU_CLIENT_SECRET=your_client_secret
```

Не публикуйте `.env` и не добавляйте реальные credentials в Git.

Без credentials доступны сохранённые карты и локальные функции. Новые карты из osu! API получить нельзя.

## Данные и резервные копии

При запуске через `run.bat` данные по умолчанию хранятся в `%LOCALAPPDATA%\OsuMapPicker`. Если предпочитаемую папку нельзя создать и она ещё не существовала, скрипт пробует `%USERPROFILE%\OsuMapPicker`. Если существующая папка недоступна для записи, приложение останавливается, не перемещая и не заменяя базу.

При запуске напрямую из исходников без переопределения пути база хранится в `data/` внутри репозитория.

Пути можно переопределить переменными окружения:

- `OSU_PICKER_DATA_DIR` — папка базы, кешей, оформления, логов и резервных копий.
- `OSU_PICKER_DB` — отдельный путь к файлу SQLite.

Создание и восстановление резервной копии доступны в `Настройки → Диагностика`. Перед ручным перемещением или заменой базы закройте приложение и сохраните резервную копию.

Если приложение сообщает об ошибке папки данных, проверьте путь и права записи. Для альтернативного пути перед запуском `run.bat` можно выполнить в командной строке:

```bat
set OSU_PICKER_DATA_DIR=%USERPROFILE%\OsuMapPicker
run.bat
```

## Разработка и тесты

Из корня репозитория в PowerShell:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt -r requirements-dev.txt
python -m pytest -q -p no:cacheprovider
```

`requirements.txt` содержит runtime-зависимости приложения. `requirements-dev.txt` добавляет инструменты для тестов и разработки. Для обычного запуска через `run.bat` устанавливать dev-зависимости не требуется.

Тесты используют моки и локальные данные; отдельная проверка реального API запускается вручную и требует credentials:

```powershell
python tools\live_api_smoke.py --pages 2
```

Этот smoke-тест выполняет реальные запросы к osu! API.

## Микробенчмарки локального чтения

После установки dev-зависимостей запустите из корня репозитория:

```powershell
python benchmarks\bench_local_reads.py --count 800 --repeat 3
```

Скрипт создаёт временную SQLite-базу с синтетическими данными и не использует сеть или пользовательскую базу. После одного прогрева он выводит медиану повторных измерений. Пример результатов на машине разработки:

| Операция | Старый путь | Новый путь | Ускорение |
| --- | ---: | ---: | ---: |
| Чтение 500 beatmapsets | 837.19 мс | 27.24 мс | 30.73× |
| Чтение 300 закешированных attributes | 436.02 мс | 2.56 мс | 170.43× |
| Страница библиотеки | 15.34 мс | 11.03 мс | 1.39× |
| Чтение полных/выбранных столбцов очереди | 5.91 мс | 3.41 мс | 1.74× |

Это микробенчмарки, а не время работы всего приложения. Результаты зависят от машины, объёма данных и прогрева файлового кеша. Измерение attributes проверяет уже сохранённые значения и не отражает сетевые запросы при первом получении данных. Сравнение очереди измеряет чтение строк SQLite, а не полный проход фонового worker.

## Основные модули

| Файл | Назначение |
| --- | --- |
| `app.py` | Интерфейс Streamlit и навигация |
| `discovery.py` | Поиск, стратегии, пагинация, обогащение и ранжирование результатов |
| `osu_api.py` | OAuth и HTTP-клиент osu! API |
| `storage.py` | SQLite, каталог, пользовательские данные, кеши и резервные копии |
| `analysis.py`, `analysis_worker.py` | Анализ `.osu`-файлов и фоновая очередь |
| `patterns.py`, `features.py`, `skillsets.py` | Признаки карты и оценка навыков |
| `filters.py`, `ranking.py`, `relevance.py` | Фильтры, обязательные целевые критерии и ранжирование |
| `presets.py` | Встроенные и пользовательские пресеты, миграции и импорт/экспорт |
| `gameplay.py` | Загрузка, разбор и предварительный просмотр `.osu` |
| `tests/` | Автоматические тесты |

## Ограничения

- Поддерживается osu!standard.
- Результаты зависят от доступных метаданных, difficulty attributes и локально проанализированных `.osu`-файлов. Неизвестные признаки не считаются автоматически отсутствующими.
- Анализ паттернов использует эвристики и не является официальной классификацией osu!.
- Превью не содержит аудио и модов; геометрия слайдеров отображается приближённо.
- Приложение рассчитано на локального пользователя. В нём нет серверной авторизации для общего удалённого использования.
